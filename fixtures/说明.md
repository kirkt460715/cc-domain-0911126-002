# 合成数据字段

planning_cases.json 记录投资成本和需求假设。changes 使用 runs.variants 的 table、id、field、value 字段；项目名和记录身份以 county.json 为准。

项目只改 rooms、buildings、stages，并可用 requires / excludes 声明依赖与互斥；情景只改 demands.students 或 buildings.closures，不附发生概率。示例中 expand-village 在校舍人数反弹时服务最好，但乡村楼临时停用时没有增益；expand-shared 在该停用情景仍有增益。二者组合在三个情景都达到事后最优，因此最小后悔选择是组合投资，而不是任一单情景的优胜项目。
